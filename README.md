# AI Agent Manager Platform — Orkas Edition

نسخه مستقل و Orkas-inspired از AI Agent Manager Platform.

> ریپوی اصلی `ai-agent-manager-platform` عمداً دست‌نخورده می‌ماند.

## هدف
این نسخه پلتفرم فعلی را به یک Agent Workforce / Agent Operating System تبدیل می‌کند:

- Commander Agent
- Dynamic Delegation
- Multi-Agent Runtime
- Structured Dispatch
- Parallel / Sequential execution
- Context Visibility Slicing
- Shared Task Plan
- Persistent Memory
- Reflection
- Skill Crystallization
- Competence tracking
- Verification loop
- Multi-model routing
- External agent adapters

## منبع پایه
`mydsoftware/ai-agent-manager-platform`

این پروژه بازطراحی مستقل قابلیت‌های معماری Orkas را روی پلتفرم Agent Manager پیاده می‌کند و قرار نیست ریپوی اصلی تغییر کند.

## وضعیت
فاز پایه Orkas Runtime در حال توسعه است. ابتدا قراردادهای هسته و Runtime اضافه می‌شوند، سپس API/Prisma/UI فعلی به آن متصل می‌شوند.
